# ostov-meta

Слой: Надстройки.

Чтение и строгая проверка конфигурации (текстовые файлы + Python), модель метаданных, версия формата, генерация заглушек `.pyi` для подсказок в IDE.

Статус: читает папку `config/` (шаг 2 ТЗ ostov-meta). Проверки ссылок и имён (`ostov check`), Python и `.pyi` пока нет.

- `load()` — манифест `ostov.yaml`, затем `catalogs/`, `documents/`, `registers/`. Возвращает все ошибки разбора сразу: файл, строка, причина.
- Разбор строгий (serde-saphyr): неизвестные ключи, повторы ключей, якоря, алиасы и `<<` запрещены; файл до 1 МБ, вложенность до 16 уровней.
- `format` в манифесте сверяется с `FORMAT_VERSION` раньше строгого разбора, чтобы файл нового формата давал ошибку о версии.
- `FieldType` разбирает `int`, `text`, `date`, `decimal(N)`, `ref(X)`; имена и типы обёрнуты в `Spanned`, у них есть строка.

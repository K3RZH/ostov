# ostov-meta

Слой: Надстройки.

Чтение и строгая проверка конфигурации (текстовые файлы + Python), модель метаданных, версия формата, генерация заглушек `.pyi` для подсказок в IDE.

Статус: читает и проверяет `config/`, отдаёт модель `ostov-model`, генерирует подсказки `.pyi`. Логика документов на Python — в `ostov-py`.

- `load(dir)` — разбор, проверка (`check`) и модель для ядра: `LocalConnector::new(ostov_meta::load(dir)?)`. Ядро от этого крейта не зависит.
- `demo()` — та же модель из встроенной в программу копии `config/` (для демо-базы); тест сверяет её с папкой.
- `parse(dir)` — файлы как есть, с номерами строк: манифест `ostov.yaml`, затем `catalogs/`, `documents/`, `registers/`, `subsystems/` (разделы меню). Все ошибки разбора сразу: файл, строка, причина.
- Разбор строгий (serde-saphyr): неизвестные ключи, повторы ключей, якоря, алиасы и `<<` запрещены; файл до 1 МБ, вложенность до 16 уровней.
- `format` в манифесте сверяется с `FORMAT_VERSION` раньше строгого разбора, чтобы файл нового формата давал ошибку о версии.
- `FieldType` разбирает `int`, `text`, `date`, `decimal(N)`, `ref(X)`; имена и типы обёрнуты в `Spanned`, у них есть строка.
- `stubs(model)` — тексты `config/_stubs/<документ>.pyi` для подсказок в IDE (СТ-03); пишет их `ostov stubs`.
- `load_with_warnings(dir)` — то же, что `load`, плюс предупреждения (`warnings`): с ними конфигурация работает.
- `Config.positions` — откуда каждый элемент. Ключи: `catalog:goods`, `catalog:goods/field:name`, `document:receipt/table:lines/field:qty`, `register:stock/field:qty` (у регистра измерения и ресурсы — `field`), `subsystem:warehouse`, `role:storekeeper`, `user_field:warehouses`, `config` (манифест). Значение — файл относительно папки конфигурации через `/`, строка и столбец имени.

## Коды `ostov check`

Вывод: `файл:строка: КОД текст`. Код постоянный: текст сообщения может меняться, код — нет. Новый код добавляется в конец своей группы, старый не переиспользуется. `E…` — ошибка, конфигурация не загрузится; `W…` — предупреждение, конфигурация работает. Константы — `ostov_meta::error::codes`.

| Код | Что не так |
|---|---|
| E001 | нет манифеста `ostov.yaml` |
| E002 | формат конфигурации (`format`) не поддерживается этой версией |
| E003 | не удалось прочитать папку |
| E004 | не удалось открыть файл |
| E005 | ошибка синтаксиса YAML или типа значения |
| E006 | якоря и алиасы запрещены |
| E007 | вложенность глубже 16 уровней |
| E008 | файл больше 1 МБ |
| E009 | неизвестный ключ |
| E010 | нет обязательного ключа |
| E011 | неизвестное значение (например, `kind` регистра) |
| E012 | ключ повторяется |
| E020 | имя не подходит: строчная латиница, цифры и `_`, первой — буква, до 63 символов |
| E021 | имя повторяется (объект, поле, табличная часть, раздел, роль, право…) |
| E022 | имя начинается с `ostov_`: так называются служебные таблицы |
| E023 | имя поля занято ядром (`id`, `version`, `posted`…) |
| E030 | точность `decimal(N)` больше 18 |
| E031 | `ref(X)`: нет справочника или документа `X` |
| E032 | нет такого значка |
| E040 | у регистра нет измерений |
| E041 | у регистра нет ресурсов |
| E042 | измерение не `ref`, `int` или `text` |
| E043 | ресурс не `decimal` |
| E044 | документ двигает регистр, которого нет |
| E050 | в `menu:` манифеста раздел, которого нет |
| E051 | раздела из `subsystems/` нет в `menu:` манифеста |
| E052 | в разделе меню нет объектов |
| E053 | в группе меню нет объектов |
| E054 | группа внутри группы |
| E055 | регистр в меню |
| E056 | в меню объект, которого нет |
| E060 | роль `admin` описана в YAML: она встроенная |
| E061 | неизвестное право или системное право |
| E062 | права на регистр в роли |
| E063 | в роли права на объект, которого нет |
| E064 | `post`/`unpost` у справочника |
| E070 | себестоимость: `qty` или `sum` не ресурс регистра |
| E071 | себестоимость: `qty` и `sum` — один ресурс |
| E072 | себестоимость: пустой `by` |
| E073 | себестоимость: в `by` не измерение регистра |
| E080 | свойство пользователя ссылается не на справочник |
| E090 | ограничение: нет такого справочника, документа или регистра |
| E091 | ограничение: в `where` нет условий |
| E092 | ограничение: у объекта нет такого поля |
| E093 | ограничение на регистр по ресурсу: можно только по измерениям |
| E094 | ограничение: `in` не вида `user.<свойство>` |
| E095 | ограничение: нет такого свойства пользователя |
| E096 | ограничение: поле и свойство разного типа (у ссылки — разная цель) |
| W001 | роль создаёт документ, но не читает справочник его обязательного поля (ADR-044) |

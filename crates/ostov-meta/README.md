# ostov-meta

Слой: Надстройки.

Чтение и строгая проверка конфигурации (текстовые файлы + Python), модель метаданных, версия формата, генерация заглушек `.pyi` для подсказок в IDE.

Статус: читает и проверяет `config/`, отдаёт модель `ostov-model`, генерирует подсказки `.pyi`. Логика документов на Python — в `ostov-py`.

- `load(dir)` — разбор, проверка (`check`) и модель для ядра: `LocalConnector::new(ostov_meta::load(dir)?)`. Ядро от этого крейта не зависит.
- `demo()` — та же модель из встроенной в программу копии `config/` (для демо-базы); тест сверяет её с папкой.
- `parse(dir)` — файлы как есть, с номерами строк: манифест `ostov.yaml`, затем `catalogs/`, `documents/`, `registers/`, `subsystems/` (разделы меню). Все ошибки разбора сразу: файл, строка, причина.
- Разбор строгий (serde-saphyr): неизвестные ключи, повторы ключей, якоря, алиасы и `<<` запрещены; файл до 1 МБ, вложенность до 16 уровней.
- `format` в манифесте сверяется с `FORMAT_VERSION` раньше строгого разбора, чтобы файл нового формата давал ошибку о версии.
- `FieldType` разбирает `int`, `text`, `date`, `decimal(N)`, `ref(X)`; имена и типы обёрнуты в `Spanned`, у них есть строка.
- `stubs(model)` — тексты `config/_stubs/<документ>.pyi` для подсказок в IDE (СТ-03); пишет их `ostov stubs`.

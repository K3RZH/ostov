# ostov-api

Слой: Layer0.

Контракт между интерфейсом и ядром: трейт Engine, команды и ответы, версия протокола. Здесь же будет описание протокола gRPC (`proto/`).

Статус: **предложение** контракта — трейты `Engine` и `Connector`, типы команд и ошибок, заглушки `StubEngine` и `StubConnector`. За основу взята заготовка из `ostov-ui/src/engine.rs`; отличия: значения полей типизированные (`Value`), id — `i64`, `seek` по номеру строки, «записать и провести» — одна команда `save(.., PostAction)`, добавлены `mark_deleted` и настройки пользователя. Без зависимостей: интерфейс подключает только этот крейт.

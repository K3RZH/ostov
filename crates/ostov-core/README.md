# ostov-core

Слой: Layer0.

Ядро: объекты, транзакции, проведение документов, регистры, закрытие периода. Реализация Engine: Local — вызов ядра в том же процессе (режим «один компьютер»). Не знает ни про интерфейс, ни про сеть.

Статус: есть транзакции (`in_transaction`) и справочник (`Catalog`): создание таблицы, запись, чтение, изменение с проверкой версии. Описание справочника пока задаётся в коде, потом его будет давать `ostov-meta`.

# ostov-cli

Слой: Надстройки.

Программа командной строки `ostov`: check, run, migrate, import, export, serve (запуск сервера).

Статус: есть `ostov check [папка]` — проверка конфигурации без базы (по умолчанию папка `config`). Печатает все ошибки как «файл:строка — причина», код выхода 1 при ошибках, 2 при неверных аргументах.

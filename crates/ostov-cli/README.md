# ostov-cli

Слой: Надстройки.

Программа командной строки `ostov`: check, run, migrate, import, export, serve (запуск сервера).

Статус: есть `ostov check [папка]` — проверка конфигурации без базы (по умолчанию папка `config`). Печатает все ошибки как «файл:строка — причина», код выхода 1 при ошибках, 2 при неверных аргументах.

`ostov stubs [папка]` — пишет подсказки `config/_stubs/<документ>.pyi` для IDE (классы документов и строк). Вместе с `config/ostov.pyi` их видит Pylance, если открыть в VS Code папку `config`.

С фичей `python` (`cargo build -p ostov-cli --features python`) `ostov check` компилирует `config/documents/*.py` и выводит ошибки как «файл:строка — причина»; без неё — предупреждение, что `.py` не проверены.

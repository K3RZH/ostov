# ostov-client

Слой: Layer0.

`Engine: Remote` (ADR-026): те же команды, что у локального ядра, но по gRPC поверх TLS. Интерфейс знает только трейт `Engine`: в режиме 2 вместо `LocalConnector` берёт `RemoteConnector::new(server_crt)` и зовёт `connect_remote("хост:порт")` (порт по умолчанию 7700) или `create_remote(адрес, "", &NewAdmin)` при первом запуске сервера. Токен сессии клиент держит сам. Отдельный крейт, чтобы приложение в режиме «один компьютер» не тянуло сетевые зависимости.

Команды синхронные (внутри свой рантайм): звать из фонового потока интерфейса, не из асинхронного кода.

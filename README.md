# Ostov

Открытая платформа для учётных систем с конфигуратором. Ранняя стадия: кода платформы ещё нет.

> «Ostov» (остов — каркас) — рабочее название, окончательное имя команда ещё не утвердила.

*English, briefly:* Ostov is an early-stage open platform for business accounting systems (catalogs, documents with posting, registers, reports, roles) with a configurator. Planned stack: Rust, Python as the configuration language, SQLite/PostgreSQL, Slint UI. There is no platform code yet; the repository currently holds only this README.

## Что это

Платформа, на которой разработчик описывает конфигурацию учётной системы (справочники, документы с проведением, регистры, отчёты, роли) текстовыми файлами в любой IDE и хранит её в git, а пользователь работает в быстром нативном приложении. Один код, два режима: «один компьютер» (база в файле) и «сервер в локальной сети».

Первая конфигурация, которую планируем написать после конфигуратора, — «Склад и рецептуры» (приход, расход, остатки, рецептуры продукции).

## Планируемый стек

- Rust: ядро, сервер, интерфейс.
- Python: язык конфигураций (подсказки в IDE, тесты, Git).
- SQL как язык запросов, только через платформу (права, диалекты); SQLite и PostgreSQL как основные СУБД, другие через адаптеры.
- Интерфейс: Slint, нативное окно на Windows и Linux (macOS позже).
- Импорт и экспорт таблиц Excel и XML.

## Статус и ближайшие шаги

Идёт подготовка: требования, дизайн и журнал решений пишутся в закрытом режиме, их опубликуем здесь вместе с каркасом проекта. Дальше: пробы (упаковка Python, формы интерфейса), ядро с SQLite, проведение и регистры, интерфейс первого режима.

Лицензия пока не выбрана (до публикации кода): все права сохранены. Принимать правки в код сейчас нельзя; если вам интересна тема, откройте задачу с вопросом или идеей.
